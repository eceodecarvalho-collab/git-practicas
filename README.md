# Prácticas de Git y GitHub

Prácticas del módulo **Git y GitHub** del máster: preparar el terminal en Windows con
**WSL + Ubuntu**, configurar Git y crear mi perfil de GitHub.

## Contenido

| Archivo | Qué hace |
|---|---|
| `instalacion-wsl-ubuntu.ps1` | Instalar WSL con Ubuntu desde PowerShell como administrador. |
| `configuracion-git.sh` | Configurar el nombre y el email de Git (`git config --global`). |

## Lo que he hecho

1. Instalar **WSL con Ubuntu** en Windows (`wsl --install -d Ubuntu`).
2. Crear mi cuenta de **GitHub**: [eceodecarvalho-collab](https://github.com/eceodecarvalho-collab).
3. Crear el repositorio especial de perfil con un **README** de presentación.
4. Configurar Git con mi nombre y email.

## Cómo usarlo

- `instalacion-wsl-ubuntu.ps1`: copia el comando en **PowerShell (Administrador)**.
- `configuracion-git.sh`: ejecútalo dentro de Ubuntu con `bash configuracion-git.sh`.

## Próximos pasos

`git init`, `git add`, `git commit` y `git push` para subir el resto de mis repositorios
(`ejercicios-pseint`, `python-basico`, `linux-terminal`).
